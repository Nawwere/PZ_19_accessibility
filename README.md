# ПЗ №19 — Основы доступности веб-страницы

## Запуск
Откройте `index.html` в браузере. Проект не требует сборки и использует локальные относительные пути.

## Выполнено
- Использованы семантические элементы `header`, `nav`, `main`, `section`, `article`, `footer`.
- Интерактивный элемент оформлен как ссылка с переходом к каталогу вместо `div` с `tabindex`.
- Добавлены осмысленные `alt` для содержательных изображений.
- Добавлена ссылка пропуска навигации к основному содержимому.
- Настроен заметный `:focus-visible`; фокус не удаляется.
- Улучшены контраст, размеры текста, адаптивность и поддержка `prefers-reduced-motion`.
- Добавлены подписи навигации и заголовочная структура.

## Проверка
Пройдите страницу клавишами Tab и Shift+Tab, активируйте ссылки клавишей Enter. Проверьте страницу в DevTools (Lighthouse / Accessibility).

## Git
Создайте собственную ветку с фамилией латиницей, зафиксируйте изменения, отправьте ветку в свой удалённый репозиторий и создайте Pull Request. Ссылки на репозиторий и PR нужно добавить в отчёт самостоятельно.
